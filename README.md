## 先搞清楚：TikTok 直播对网络到底有什么要求

TikTok 官方直播工作室的帮助文档里有一个很实际的建议：对大多数场景，720P 就够了，因为观众主要用手机看直播，没必要一上来就追 1080P 高码率。按第三方整理的数据，TikTok 日常推流码率平均在 2Mbps 左右，高规格直播会到 5Mbps 上下。

换算成带宽要求，业内常用的稳妥做法是把推流码率控制在上行带宽的七成左右，留出余量应对抖动。也就是说，想稳稳推一路 720P，3~5Mbps 的持续上行是底线；想做 1080P 高帧率，10Mbps 起步比较踏实。

比峰值速度更重要的是“持续上传能力”。Mkcloud 在自己的知识库里也强调过这一点：单次测速跑出漂亮数字没有意义，抖动和长时间任务的表现才决定直播稳不稳。这正是专线和普通家宽、普通代理的差别所在——专线卖的不是峰值，是持续。

## 直播卡顿排查清单：一层一层剥，别一上来就换线路

直播卡顿应先区分编码、设备、本地上传、网络路径与平台限制，这是 Mkcloud 官方知识库给出的排查顺序，逻辑很清楚：

1. **推流端负载**。先看推流软件的编码负载和丢帧类型，CPU、GPU 被占满导致的卡顿，换什么线路都没用。
2. **本地上传**。本地宽带的上行如果本身不稳，问题在源头。另外有一个常被忽略的点：如果推流程序跑在本地电脑上，通过远程桌面连上 VPS 并不会让本地推流自动改走那条线路——流量走不走专线，取决于业务实际运行在哪台机器上。
3. **跨境链路**。前两项都排除后，再用相同目标、相近时段做对照测试，确认是不是线路的问题。官方建议保存推流日志再对比，别凭感觉。
4. **平台限制**。视频零播放、账号审核异常、直播间被限推荐，这些属于账号和内容层面的风控，不是买专线能解决的。专线解决的是“连接质量”，不是“账号信用”。

第四点值得加粗说一遍：**独享 IP 不保证平台不限流、不封号**。这是 Mkcloud 官方原话，不是我这个编辑替它谦虚。

## 直播线路怎么选：IEPL、IPLC、IXP 的差别和按目标市场对号入座

跨境专线常见的三种技术形态，区别主要在链路性质和延迟：

- **IEPL**：点到点以太网专线，端内延迟最低，适合对稳定性要求最高的场景。Mkcloud 的广港 IEPL 端内延迟标称 1~2ms。
- **IPLC**：国际专线线路，上海到日本标称 25~28ms，上海到美国 124~134ms，上海到香港 21ms。延迟比 IEPL 高，但方向选择多。
- **IXP**：云厂商 BGP 网络优化入口，1~2ms 端内延迟，但要求你的前置设备必须跑在受支持的云厂 BGP 网络上（腾讯云、百度云、火山云华南、华为云华南等），不适合普通家宽直连。

选线路的顺序是先定目标市场，再定国内入口，最后比带宽和流量。整理成对照：

| 你的直播目标 | 对应线路 | 参考端内延迟 |
| --- | --- | --- |
| 美国市场直播带货 | 沪美 IPLC | 124~134ms |
| 日本市场直播 | 沪日 IPLC | 25~28ms |
| 香港出口中转、华南团队 | 广港 IEPL | 1~2ms |
| 上海入口到香港出口 | 沪港 IPLC | 21ms |
| 已有云厂 BGP 环境 | 深港 IX | 1~2ms |
| 高防需求 | 厦港高防 IPLC | 1~2ms |

两个必须提前知道的边界：第一，香港出口不等于美国或东南亚本地出口，官方明确提示不能把香港或日本出口当成新加坡、韩国等当地节点用；第二，Mkcloud 的出口是服务器 BGP IP，官方没有承诺住宅属性和平台解锁，如果你的运营方案依赖住宅 IP 纯净度，这一点要单独评估，别被任何“买线保号”的说法带偏。

## 常见问题

**推流软件到底应该装在哪台机器上？** 装在哪台机器上，流量就从哪里走。推流程序在本地，那么本地网络就是第一跳；想走专线，业务就要实际跑在专线 VPS 上。官方特别提醒过：远程桌面连上 VPS，不会自动把你本地的推流改道，也不默认所有直播工作流都适配 VPS，摄像头采集类直播尤其要先确认方案可行。

**一条线能带几个账号？** Mkcloud 官方的态度是别把“一号一 VPS”当成通用风控铁律，按平台规则和实际用量来。第三方运营内容里比较常见的建议是一 IP 一到三个账号，再多就有关联风险——两种说法可以互相参照，核心是别把十几个号压在一条线上。

**现在有没有能用的优惠码？** 据官方知识库，此前的双旦活动码已过期，沪港 IPLC 新品折扣 9 月 4 日也已结束。目前以商店实时标价为准，遇到所谓“内部折扣码”的信息先核实再信。

**买专线能保证不被限流封号吗？** 不能。官方写明独享 IP 不保证平台批准账号、不限流或不封号。专线改善的是连接质量这个变量，账号内容、行为、资质是另外的变量。

**目标市场在东南亚或英国怎么办？** Mkcloud 目前没有东南亚、英国等当地出口产品，官方也不建议把香港出口冒充当地网络。做这些市场的本地直播间，需要另寻有当地出口的服务商，这一点别硬凑。
